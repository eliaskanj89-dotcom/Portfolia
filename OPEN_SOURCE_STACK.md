# Portfolia open-source stack

- Portfolio Performance — EPL-1.0 — behavior/parity reference; direct adaptations retain applicable EPL obligations.
- Supabase / supabase-js — Postgres, Auth and RLS foundation.
- yahoo-finance2 — MIT — server-side quote adapter; market-data provider terms remain separate.
- PyXIRR — Unlicense — XIRR/IRR/NPV engine.
- Playwright — Apache-2.0 — browser/mobile E2E QA.

## Reference only
Ghostfolio and Flowfolio are AGPL-3.0. Their product/architecture ideas are useful, but their source is not copied into Portfolia under the current licensing strategy.
